# República da Praia — projeto organizado

- index.html
- css/style.css
- js/app.js
- assets/ (imagens)
- backend/ (API agenda)

## Deploy (site)
Publique a pasta raiz como site estático.

## Deploy (backend)
Suba a pasta backend como Web Service (Node) no Render e configure as variáveis de ambiente já usadas.


## Painel de conteúdo do site
- `admin-aulas.html`: criar, editar e excluir modalidades, preços e horários.
- `admin-site.html`: editar os textos principais e as fotos/legendas da galeria.
- As configurações ficam no backend; use `DATA_DIR` em um disco persistente do Render para preservar alterações e fotos entre deploys.
